# 大富翁 · 联机版

经典 40 格大富翁棋盘，完整规则实现，支持单机 AI、本地热座和局域网联机。零第三方依赖。

## 启动

```powershell
cd monopoly
node server.js
```

浏览器打开 `http://localhost:8787`。启动时还会打印局域网地址（如 `http://192.168.31.25:8787`），同一网络下的朋友直接访问该地址即可联机。

改端口：`$env:PORT=9000; node server.js`
仅本机可访问：`$env:HOST="127.0.0.1"; node server.js`

## 三种玩法

| 模式 | 说明 |
| --- | --- |
| 单机对战 | 你 + 1~7 个 AI 对手，AI 会购买、竞拍、盖房、抵押、筹钱还债并宣布破产 |
| 本地热座 | 2~8 人共用一台设备轮流操作 |
| 联机房间 | 房主创建 4 位房间号，朋友输入房间号加入，最多 8 人（可再加 AI 补位） |

联机流程：创建房间 → 把房间号（或局域网 IP）发给朋友 → 朋友打开同一地址、填昵称、选「联机房间」→ 输入房间号 → 房主点「开始联机对局」。

勾选「公开房间」后，房间会出现在大厅的公开房间列表里，陌生人可以直接点「加入」；取消勾选则只能凭房间号进入。

## 规则实现

- 起始资金、经过起点薪水、监狱与保释金（含三次掷骰失败强制缴费）、出狱免费卡
- 掷出双数追加一次，连续三次双数直接入狱
- 无人购买的地产可买下；放弃时按官方规则进入拍卖，价高者得
- 集齐色组后基本租金翻倍；铁路按持有数量递增（$25/$50/$100/$200）；公用事业按点数 4 倍或 10 倍
- 房屋需集齐色组且均衡建造，4 栋房屋后可升级旅馆；拆除按半价回收
- 抵押获得地价一半，赎回支付 55%，有房屋的色组不能抵押
- 现金不足时进入筹款状态：可拆房、抵押、交易，仍不足则破产，资产移交债权人
- 机会 / 社区福利完整卡组（16 + 16 张，含前往指定地块、修缮费、生日收钱等）
- 自由交易：地产 + 现金 + 出狱免费卡任意组合，带房屋的色组不可拆分转让
- 最后未破产者获胜

大厅可切换的房规：初始资金、经过起点金额、流拍是否拍卖、免费停车奖池、停在起点双倍、保释金、AI 行动速度。

## 操作

- 点棋盘任意格子查看地价、租金表和建造 / 抵押按钮
- 点玩家卡片里的地产标签也可打开该地产
- 空格键掷骰，Esc 关闭弹窗
- 右侧「战况」看流水，「聊天」内可实时聊天

## 部署成公网网站

代码里没有任何第三方依赖，只要能跑 Node 18+ 就能上线。客户端会自动根据页面协议选择 `ws` 或 `wss`，所以放在 HTTPS 反向代理后面即可。

**方式一：Docker（任意云主机 / NAS）**

```bash
docker build -t monopoly .
docker run -d --name monopoly -p 80:8787 -e PORT=8787 monopoly
```

再用 Nginx 或 Caddy 挂上域名与证书（Caddy 两行即可自动申请 HTTPS）：

```
game.example.com {
    reverse_proxy 127.0.0.1:8787
}
```

反代需要放行 WebSocket 升级头（Caddy 默认支持；Nginx 需加 `proxy_set_header Upgrade $http_upgrade;` 与 `proxy_set_header Connection "upgrade";`）。

**方式二：Render（免费套餐，自带 HTTPS 与 WebSocket）**

把项目推到 GitHub，在 Render 选 **New → Blueprint** 指向仓库，`render.yaml` 会自动建好服务；也可以手动建 Web Service 并选择 Docker 环境。

**环境变量**

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `PORT` | `8787` | 监听端口，PaaS 一般会自动注入 |
| `HOST` | `0.0.0.0` | 监听地址，设 `127.0.0.1` 则仅本机可访问 |
| `MAX_ROOMS` | `800` | 单进程房间上限 |
| `MAX_ROOM_SIZE` | `8` | 单个房间人数上限 |

已内置的安全措施：CSP 等安全响应头、每连接消息限流（10 秒 300 条）、房间与人数上限、6 小时空房清理、25 秒心跳保活、昵称长度与控制字符过滤。

## 联机说明

对局状态由房主浏览器作为权威端，服务器转发并保存最近一次快照。房主离开时，房间自动把房主身份和状态交给下一位玩家继续；断线的玩家重新加入同房间会收到当前快照。

因为服务器只做转发、不跑规则，单台小机器（1 核 512MB）可以同时承载数百个房间；代价是房主的浏览器标签页需要保持打开，关掉页面等于离开对局。

快速试玩：URL 加 `?demo=3` 可直接开局对抗 3 个 AI。
